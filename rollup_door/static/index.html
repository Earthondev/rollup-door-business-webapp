สมุดเรียนงานช่างประตูม้วน

จดสิ่งที่เจอหน้างานจริงทุกวัน เก็บความรู้ ต้นทุน ราคา วัสดุ และไอเดียธุรกิจ เพื่อเอาไปทำกิจการของตัวเองในอนาคต

กรอกเฉพาะที่มีได้เลย ช่องไหนยังไม่รู้เว้นว่างได้

ตั้งค่า Access Key (กรอกครั้งแรก)

ระบบจะบันทึกค่าไว้ในเครื่องนี้ เพื่อส่งคำขอแบบ signed

เช็กอินรายวัน
